---
version: '6.5.1'
date: '2026-11-13'
title: Block executable frontmatter in documentation
badge: security
---

RDX now accepts only YAML or JSON frontmatter when indexing or loading Markdown
and MDX pages. Previously, a document with JavaScript frontmatter could execute
code in the Node.js process during those operations.

Update to RDX 6.5.1 and rebuild your documentation to apply the fix. Existing
YAML and JSON frontmatter works as before.
