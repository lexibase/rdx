title: Documentation that AI assistants can follow
---

AI assistants learned RDX from whatever version existed when they were trained.
RDX 7.1 gives them the documentation of the version you actually use, and lets
your readers bring any page of your site into a chat with one click. New
projects also start as a Git repository.

## Coding agents read the docs of your RDX version

`@lexibase/rdx` now ships its documentation as Markdown in
`node_modules/@lexibase/rdx/dist/docs/`, with an `index.md` that lists every
page. Updating RDX updates the files, so they always match the installed
version and work offline.

New projects include an `AGENTS.md` that tells agents such as Claude Code, Codex
and Cursor to read those files before changing your documentation. RDX keeps its
section up to date whenever you run `rdx dev`, `build`, `start` or `prepare`,
and leaves the rest of the file to you. To add the section to an existing
project, put the two markers in an `AGENTS.md` at the root:

```md title="AGENTS.md"
<!-- BEGIN:rdx-agent-rules -->
<!-- END:rdx-agent-rules -->
```

Then prepare the project, and RDX fills in the section:

:::tabs

### pnpm

pnpm rdx prepare

### npm

npm exec -- rdx prepare

### yarn

yarn rdx prepare

:::

See [AI coding agents](/docs/7.1.0/ai-agents) for the full section and how to
opt out.

## Your published site has an index for every edition

Tools that only know your domain look for `/llms.txt` first. RDX now publishes
it at the site root, linking to the documentation index of each language and
edition. Each published edition also gets its own index, such as
`/docs/1.2.0/llms.txt`, so a tool can follow an older version of your
documentation. If you already maintain `public/llms.txt`, RDX keeps serving
yours.

## Readers can ask Claude or ChatGPT about a page

The **Copy this page** menu now has **Open in Claude** and **Open in ChatGPT**.
Each opens a new chat with a ready prompt that links to the page's Markdown
export and to `/llms.txt`. The reader sends the prompt; RDX shares nothing by
itself. The assistant reads your public site, so pages behind a login stay out
of reach.

The prompt is an interface text, so you can translate it in `_labels.json`
like any other. See
[Read a page as Markdown](/docs/7.1.0/llms#read-a-page-as-markdown).

## New projects start with Git

After installing dependencies, `create-rdx` initializes a Git repository and
records an initial commit with your lockfile and `AGENTS.md`. It skips this step
inside an existing repository, such as a monorepo, or when Git is not available.
Pass `--no-git` to skip it yourself. See
[Create a project](/docs/7.1.0/cli#create-a-project).
