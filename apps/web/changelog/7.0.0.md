---

RDX 7 gathers every text that is not part of your documents into a single
catalog per language: the interface, from **On this page** to **Copy code**, and
the category names in your sidebar. Phones also get a navigation drawer that
puts the page tree, editions and languages one tap away.

> [!WARNING] Read the migration guide before updating
> RDX now ships its interface text in English only. A site in Portuguese or any
> other language shows interface text in English until you translate it in
> `_labels.json`. `_category.json` is no longer read either. The
> [migration guide](/docs/7.0.0/migrating-6-to-7) walks through both changes.

## Translate the interface and the sidebar in one file

Run `rdx i18n sync` and RDX creates `_labels.json` for every language that needs
it, listing each interface text and each category name from all your editions:

:::tabs

### pnpm

pnpm rdx i18n sync

### npm

npm exec -- rdx i18n sync

### yarn

yarn rdx i18n sync

:::

The keys are the English text, so you always know what you are translating. An
empty value keeps the original, which means a half-translated catalog never
breaks the site. A translation that loses a placeholder such as `{version}` is
ignored instead of hiding the version number.

The same file renames categories without touching folders or URLs, even on a
site with a single language and no plugin. Running the command again only adds
what is new and never erases your translations. When a category disappears from
every edition, `rdx check` points out the leftover entry, and
`rdx i18n sync --prune` removes it for you.

See [Translate the interface and categories](/docs/7.0.0/languages#translate-the-interface-and-categories)
for the complete format.

## Navigate comfortably on a phone

On screens narrower than 768px, the navbar keeps the logo and search, and a
single button opens everything else in a drawer that slides in from the right.
On documentation pages, it opens straight to the page tree. **Main menu** leads
to the edition, the language, the site links and the theme toggle, and each list
slides in the same drawer, with **Back** to return.

See [Page navigation](/docs/7.0.0/create-docs#page-navigation) for the details.

## Start a project in your language

`create-rdx` now asks for the primary language of your documentation. For a
language other than English, the new project already includes its `_labels.json`,
ready to translate. Skip the question with `--lang`:

:::tabs

### pnpm

pnpm create @lexibase/rdx@latest my-docs --lang pt-BR

### npm

npm create @lexibase/rdx@latest -- my-docs --lang pt-BR

### yarn

yarn dlx @lexibase/create-rdx@latest my-docs --lang pt-BR

:::

See [Installation](/docs/7.0.0/installation) for every option.

## Smaller changes

- The last updated date is written in the page language, such as
  "25 de agosto de 2026" on a Portuguese page.
- The archived edition badge now reads **Archived edition**. Map it in
  `_labels.json` to keep the previous text.
- The GitHub link in the navbar uses the official GitHub mark.
- The navbar home link is announced by its visible title, so screen readers and
  the screen agree.

## Update your project

Update the framework and your optional plugins, run `rdx i18n sync`, translate
what you need, and replace any `_category.json` files. The
[migration guide](/docs/7.0.0/migrating-6-to-7) covers each step, and
[Updating RDX](/docs/7.0.0/updating) lists the commands.
