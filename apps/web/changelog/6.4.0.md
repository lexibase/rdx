title: Give your releases a home in your docs
---

This is the first RDX release announced with its own changelog plugin. If your
project publishes release notes, run `rdx add changelog` to add a **Changelog**
link to the navbar. Run `rdx changelog new 1.2.0` with your release number, then
write the announcement in the Markdown file it creates under `changelog/`.

Readers can jump to a release, copy its link or Markdown, and follow the
changelog through RSS. Add badges for breaking changes, security updates, or
deprecations to let readers filter the list. You can also put a link to a
migration guide or security advisory right below the release title.

`rdx check` and `rdx build` now catch broken local links, missing section anchors,
and missing images or downloads in release notes. The navbar also underlines
the section you are reading, and the Configuration guide lists the accepted
values and defaults for every `rdx.config.ts` option.
