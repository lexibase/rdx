---
title: Migrating sidebar ordering
description: Move an existing sidebar to numbered folders and the order field.
order: 4
---

Use this guide to migrate a project that uses `link_position` or
`_category.json` for its sidebar. For new projects, see
[Categories and URLs](../03-writing-documentation/docs.mdx#categories-and-urls).

## Update page frontmatter

Replace `link_position` with `order` and keep the same number. RDX still reads
`link_position` when `order` is absent.

```diff
 ---
 title: Install and configure your project
 description: Set up your documentation project and start writing.
-link_position: 2
+order: 2
 ---
```

If the sidebar needs a shorter label, add `navTitle: Installation`.

## Move the category order into the folder name

Use the old `sidebar_position` as a two-digit folder prefix. For example, rename
`docs/guides/` to `docs/02-guides/` to put it in position 2. A page inside that
folder still uses `/docs/guides/` in its URL. Update relative Markdown links to
use the actual path, including the prefix.

Remove `_category.json` once the folder name gives you the label you want.
Keep the file if you need a custom label while retaining the same URL path.
If you keep it, remove `sidebar_position` to let the folder prefix set the order.

## Check existing links

Run `rdx check` after renaming files. If your source names already started with
two-digit prefixes, review public links to those pages. RDX now omits those
prefixes from generated URLs.
