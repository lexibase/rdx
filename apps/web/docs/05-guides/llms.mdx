RDX automatically publishes a Markdown index at `/docs/llms.txt`. The index
groups pages by category and links to their Markdown exports. Open the file in
a browser or give its URL to a tool that reads documentation.

If you already maintain `public/docs/llms.txt`, RDX serves that file at the
same address.

## Find the right edition and language

With versioning enabled, the index lists the latest active published edition.
Before the first publication, it lists the live documentation. The index at
`/docs/llms.txt` uses the default language. Translated documentation also has
an index under its language path, such as `/pt-br/docs/llms.txt`, which lists
pages with an authored translation.

Set `metadata.metadataBase` in `rdx.config.ts` to your public site URL if you
want absolute links in the index and exports.

## Read a page as Markdown

Follow a link in the index. You can also derive the export URL by prepending
`/rdx-markdown` to the public page path and appending `.md`. For example,
`/docs/guides/intro` becomes `/rdx-markdown/docs/guides/intro.md`.

The export includes the page title, description when supplied, `url` for the
source page, and `docs_index` for the corresponding index. Relative document
links resolve to public page URLs. RDX generates the export from your content
without editing the Markdown file you authored.
