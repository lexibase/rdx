## Display a key

Write `:kbd[Key]` in your `.mdx` pages. No import or plugin is required:

Press :kbd[Esc] to close a dialog or :kbd[Enter] to confirm.

```md
Press :kbd[Esc] to close a dialog or :kbd[Enter] to confirm.
```

## Write a shortcut

Write the separator as ordinary text between the keys:

Press :kbd[Ctrl] + :kbd[K] to open search.

```md
Press :kbd[Ctrl] + :kbd[K] to open search.
```
