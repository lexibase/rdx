### Five-column comparison

Markdown tables use the shared shadcn/ui Table components, with the RDX
documentation styling. Column alignment follows the Markdown separator row.

Wider tables scroll horizontally on small screens without widening the page.

| Feature | Description | Status | Plugin | Example |
| :------ | :---------- | :----: | :----: | :------ |
| Markdown | Write headings, lists, and paragraphs | Included | Not required | `## Heading` |
| Callout | Highlight contextual information | Included | Not required | `<Callout>` |
| Code block | Display source code with a copy button | Included | Not required | `pnpm dev` |
| Blockquote | Quote a passage or explanation | Included | Not required | `> A quotation` |

Table cells can contain [keyboard shortcut components](./keyboard-shortcuts.mdx)
such as `<Kbd>Esc</Kbd>`.

### Syntax highlighting

Set the language after the opening fence. Highlighting follows the light/dark
theme automatically, without changing how code is copied.

```tsx
export function Welcome() {
  return <h1 className="text-xl">Welcome to RDX</h1>
}
```

```py
def greet(name):
    return f"Hello, {name}!"
```
