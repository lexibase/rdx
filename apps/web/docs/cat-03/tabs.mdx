## Choose your package manager

Use the arrow keys to move between tabs and Enter or Space to select one.
Tabs are included in RDX without imports or plugins.

<Tabs defaultValue="pnpm">

    <TabsTrigger value="yarn">yarn</TabsTrigger>

## Write your own tabs

```mdx
<Tabs defaultValue="pnpm">
  <TabsList aria-label="Package manager">
    <TabsTrigger value="pnpm">pnpm</TabsTrigger>
    <TabsTrigger value="npm">npm</TabsTrigger>
  </TabsList>
  <TabsContent value="pnpm">

Run `pnpm install`.

  </TabsContent>
  <TabsContent value="npm">

Run `npm install`.

  </TabsContent>
</Tabs>
```

Use matching, unique values for triggers and panels. Set `defaultValue` to an
enabled tab and give the list an accessible label. The icon-only copy button
copies the selected panel as plain text, without its tab label or button text.

## Combine with Markdown

Each group maintains its own selection. Panels support normal Markdown and RDX components.

<Tabs defaultValue="development">
  <TabsList aria-label="Environment">
    <TabsTrigger value="development">Development</TabsTrigger>
    <TabsTrigger value="production">Production</TabsTrigger>
    <TabsTrigger value="preview" disabled>Preview (soon)</TabsTrigger>
  </TabsList>
  <TabsContent value="development">

<Callout variant="tip" title="Live updates">

Run `pnpm dev` and edit your documentation to see changes locally.

</Callout>

  </TabsContent>
  <TabsContent value="production">

1. Run `pnpm build`.
2. Run `pnpm start` to check the production site.

  </TabsContent>
</Tabs>
