## Add a public file

Place files in `public/` beside `docs/`:

```text
my-docs/
  docs/
  public/
    images/
      diagram.svg
    files/
      manual.pdf
  rdx.config.ts
```

Use URLs without `public`:

```md
![Architecture diagram](/images/diagram.svg)

[Download the manual](/files/manual.pdf)
```

Root-relative URLs work from nested documents and version snapshots.

## Development and production

The generated runtime links its internal public directory to your original
`public/`; it does not keep a stale copied cache. Edit the project-owned files.
Rebuild/redeploy after production asset changes.

For favicon, share images, and the web app manifest, also configure their paths
in [metadata](../cat-02/config.mdx#seo-and-social-previews).

## Shared across versions

The versioning plugin snapshots MDX, not public assets. Use paths such as
`/images/1.0.0/diagram.svg` when historical documentation must retain an old image.

All files in `public/` are public. Do not store credentials, private documents,
or internal configuration there.
