## License

RDX is released under the **MIT License**. You can use and modify it, including
in commercial projects, under the terms of the
[repository license](https://github.com/lexibase/rdx/blob/main/LICENSE).
Dependencies retain their own licenses.

## Report a problem

Open an [issue on GitHub](https://github.com/lexibase/rdx/issues) with your Node.js
version, operating system, package manager, RDX package versions, and the smallest
example that reproduces the problem. Remove secrets from logs before sharing them.

## Contribute

The official website is also RDX's development application. Shared behavior belongs
in the framework packages so that CLI-generated sites receive the same improvements.

Read [Development](../cat-05/development.mdx) for local setup and validation.
