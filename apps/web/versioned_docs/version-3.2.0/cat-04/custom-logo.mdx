## Create the logo component

Create a `components/` folder at the project root to organize your custom React
components. Save your SVG component in `components/logo.tsx`:

```folder
my-docs/
  components/
    logo.tsx
  docs/
  public/
  rdx.config.ts
  tsconfig.json
```

The default RDX logo is an SVG rendered by a React component. Your custom logo
uses the same format:

```tsx
// components/logo.tsx
export function Logo({ className }: { className?: string }) {
  return (
    <svg
      xmlns="http://www.w3.org/2000/svg"
      viewBox="0 0 24 24"
      fill="none"
      stroke="currentColor"
      strokeWidth={1.5}
      className={className}
      aria-hidden="true"
    >
      <path d="M3 4h7a2 2 0 0 1 2 2v15a3 3 0 0 0-3-3H3V4Z" />
      <path d="M21 4h-7a2 2 0 0 0-2 2v15a3 3 0 0 1 3-3h6V4Z" />
    </svg>
  )
}
```

Replace the example SVG with your own artwork. Keep its original `viewBox` and
paths, and pass `className` to the outer `<svg>` so RDX can size the logo for
each location. Avoid fixed `width` and `height` styles that override that sizing.

SVG attributes use React names: `class` becomes `className`, `stroke-width`
becomes `strokeWidth`, and `fill-rule` becomes `fillRule`.

For a single-color logo, `fill="currentColor"` or `stroke="currentColor"` follows
the interface's text color in light and dark mode. Keep your own fill and stroke
colors for multicolor artwork.

## Configure the logo

Import the component in `rdx.config.ts` and assign it to `navbar.logo`:

```ts
import { defineConfig } from '@lexibase/rdx'
import { Logo } from './components/logo'

export default defineConfig({
  metadata: {
    applicationName: 'My project',
  },
  navbar: {
    title: '',
    logo: Logo,
  },
})
```

Add the import and `logo` option to your existing configuration, keeping your
other settings. Pass `Logo`, the component itself; RDX renders it with the
appropriate styling. An empty `navbar.title` displays only the logo. Set a title
to show text beside it.

The example uses a named export. If your component uses `export default`, use
`import Logo from './components/logo'` instead.

The same component appears in the [built-in homepage](./homepage.mdx) when it is
enabled. A custom `components/home.tsx` controls its own content and can import
`Logo` from `./logo`. Restart `pnpm dev` after changing configuration, or rebuild
and redeploy for production.

## Configure the browser icon

`navbar.logo` controls the visible site branding. Configure the browser-tab icon
with `metadata.icons`. For an SVG favicon, place the file at
`public/favicon.svg` and add this field to your existing `metadata` object:

```ts
icons: {
  icon: {
    url: '/favicon.svg',
    type: 'image/svg+xml',
  },
},
```

See [Public files](../cat-05/assets.mdx) for asset paths and
[Configuration](../cat-02/config.mdx) for other metadata options.

## TypeScript setup

Keep `tsconfig.json` at your documentation project's root, beside
`rdx.config.ts`. Local React components need these settings inside
`compilerOptions`:

```json
{
  "jsx": "react-jsx",
  "module": "esnext",
  "moduleResolution": "bundler"
}
```

Include your `components/` files in that configuration. This lets the editor
check JSX and resolve imports such as `./components/logo` without file
extensions, including when the documentation is inside a monorepo.
