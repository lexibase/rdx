## Write a Callout

No import or plugin is required:

```mdx
<Callout variant="tip" title="A useful shortcut">

Use **Markdown**, `inline code`, links, and lists inside the component.

</Callout>
```

Variants are `note` (the default), `tip`, `success`, `warning`, and `danger`.
The title is optional. Keep blank lines around Markdown content.

## Use in React

In a project-owned React file, import the shared component normally:

```tsx
import { Callout } from '@lexibase/rdx-ui/components/callout'

export default function Notice() {
  return <Callout title="Welcome">Read the guide to get started.</Callout>
}
```

Callouts are static notes, not live alerts. Use ordinary paragraphs for essential
instructions; do not turn every paragraph into a box.
