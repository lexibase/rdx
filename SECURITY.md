# Security policy

## Report a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/lexibase/rdx/security/advisories/new)
to share security findings with the RDX maintainers. Keep vulnerability details
private while we investigate and coordinate a fix.

Please include:

- The affected RDX package and version, and the Node.js version if relevant.
- The steps to reproduce the issue and, if possible, a minimal example.
- The impact and any conditions needed to reproduce it.

Remove credentials, tokens, and personal data from examples and logs before
submitting the report.
