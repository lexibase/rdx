## Highlight important information

Callouts are included in RDX. No import or plugin is required.

<Callout title="A useful note">

Keep supporting information close to the documentation it explains.

</Callout>

<Callout variant="tip" title="A helpful tip">

You can use **Markdown**, [documentation links](/docs/init/intro), and `inline code` inside a callout.

</Callout>

<Callout variant="success" title="Ready to go">

Your documentation is ready to share.

</Callout>

<Callout variant="warning" title="Before updating">

- Read the release notes.
- Test your changes before deploying.

</Callout>

<Callout variant="danger" title="Irreversible action">

Deleting the source files permanently removes their content.

</Callout>

<Callout>

A title is optional. The default variant is `note`.

</Callout>

## Syntax

```mdx
<Callout variant="warning" title="Before updating">

Test your changes before deploying.

</Callout>
```
