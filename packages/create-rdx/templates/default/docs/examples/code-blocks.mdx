## Show a filename

Place `title="filename"` after the fence language:

````md
```ts title="rdx.config.ts"
const search = true
```
````

```ts title="rdx.config.ts"
const search = true
```

The title appears in the header; copying keeps only the code. Titles with spaces
use quotes, such as `title="Install dependencies"`.

## Number lines

Add `lineNumbers` to start at 1, or use `startLine` for a fragment of a larger file:

````md
```ts title="example.ts" lineNumbers startLine=20
const enabled = true
console.log(enabled)
```
````

```ts title="example.ts" lineNumbers startLine=20
const enabled = true
console.log(enabled)
```

`lineNumbers` enables numbering when present; omit it to keep numbers hidden.
`startLine` is a positive integer that sets the starting value when numbering
is enabled. Copying excludes the line numbers.

## Compare changes

Use a `diff` fence. Prefix removed lines with `-`, added lines with `+`,
and unchanged lines with a space. The copy button copies the patch as shown.

```diff
-const search = false
+const search = true
 console.log(search)
```

## Draw a folder tree

Use a `folder` fence with two spaces per level. End folder names with `/`.
The diagram's branches are generated from those indents.

```folder
my-docs/
  docs/
    guides/
      introduction.mdx
  public/
    images/
      logo.svg
  components/
    home.tsx
  rdx.config.ts
```

Use `text` instead to display a diagram you have already drawn. Long lines
scroll inside the block. The icon in the header copies the rendered tree.
