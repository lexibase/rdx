## Choose your package manager

Wrap related examples in `:::tabs`. Each direct `### Title` creates a tab;
its content continues until the next title or the closing `:::`.
The first tab is selected initially. No import or plugin is required.

:::tabs

### pnpm

pnpm install

### npm

npm install

### yarn

yarn install

:::

## Write your own tabs

```md
:::tabs

### pnpm

pnpm install

### npm

npm install

### yarn

yarn install

:::
```

Use the arrow keys to move between tabs and Enter or Space to select one.
The icon-only copy button copies the selected panel as plain text, including
complete code blocks. Each group maintains its own selection.

## Combine with Markdown

Panels support paragraphs, lists, code blocks, Callouts and other RDX components.
Use `####` or deeper headings for subsections inside a panel. Direct `###`
headings are reserved for tab labels within the container.

:::tabs

### Development

> [!TIP] Live updates
> Keep the development server running while editing your documentation.

### Production

1. Build your documentation.
2. Start the production server to check the result.

:::

## JSX syntax

Use JSX for explicit values, a custom accessible label or disabled tabs:

```mdx
<Tabs defaultValue="development">
  <TabsList aria-label="Environment">
    <TabsTrigger value="development">Development</TabsTrigger>
    <TabsTrigger value="production">Production</TabsTrigger>
    <TabsTrigger value="preview" disabled>Preview</TabsTrigger>
  </TabsList>
  <TabsContent value="development">

Keep the development server running.

  </TabsContent>
  <TabsContent value="production">

Build and check your production site.

  </TabsContent>
</Tabs>
```

Use matching, unique values for triggers and panels. Set `defaultValue` to an
enabled tab. Keep blank lines around Markdown inside JSX.
