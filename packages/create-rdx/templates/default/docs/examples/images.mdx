## Images

Put images inside `public/` and reference them from the site root:

![RDX logo](/images/rdx.svg)

```md
![RDX logo](/images/rdx.svg)
```

Click the image to open its preview, or focus it and press Enter or Space.
Press Escape, use the close button, or click outside to return to the page.
Images inside links follow the link; images with empty alt text are decorative.

The file above lives at `public/images/rdx.svg`, not in `docs/` or `.rdx/`.

## Downloads

Put downloadable files in `public/` too:

[Download the example file](/downloads/example.txt)

```md
[Download the example file](/downloads/example.txt)
```

Use `/images/rdx.svg`, not `/public/images/rdx.svg`. Files in `public/` are
publicly accessible: never put passwords, tokens or private documents there.

All documentation versions share these files. To preserve an image for a
snapshot, keep a version-specific filename, such as `/images/1.0.0/diagram.svg`.
