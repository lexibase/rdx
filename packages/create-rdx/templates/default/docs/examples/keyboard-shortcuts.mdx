## Display a key

Write `:kbd[Key]` in your `.mdx` pages. No import or plugin is required:

Press :kbd[Esc] to close a dialog or :kbd[Enter] to confirm.

```md
Press :kbd[Esc] to close a dialog or :kbd[Enter] to confirm.
```

## Write a shortcut

Write the separator as ordinary text between the keys:

Press :kbd[Ctrl] + :kbd[K] to open search.

```md
Press :kbd[Ctrl] + :kbd[K] to open search.
```

These shared shadcn/ui components render semantic `<kbd>` elements and follow
the site's light and dark themes. Use them to describe shortcuts supported by
your application.

## JSX syntax

Use `KbdGroup` to keep a combination together. Add accessible names for symbols:

<KbdGroup aria-label="Command plus K">
  <Kbd aria-label="Command">⌘</Kbd>+<Kbd>K</Kbd>
</KbdGroup>

```mdx
<KbdGroup aria-label="Command plus K">
  <Kbd aria-label="Command">⌘</Kbd>+<Kbd>K</Kbd>
</KbdGroup>
```

## Use in custom React components

Import the shared components in your own `components/` files:

```tsx
import { Kbd, KbdGroup } from '@lexibase/rdx/ui/components/kbd'

export function SearchShortcut() {
  return (
    <KbdGroup aria-label="Control plus K">
      <Kbd>Ctrl</Kbd>+<Kbd>K</Kbd>
    </KbdGroup>
  )
}
```
